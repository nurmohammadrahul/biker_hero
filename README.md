# 🏍️ Biker Hero

**Biker Hero** is a sleek, responsive landing page for a fictional bike sales company. Built with **HTML**, **Tailwind CSS**, and **JavaScript**, it showcases a modern design, smooth layout, and essential UI components for a promotional or product-based website.

🔗 **Live Site**: [https://nurmohammadrahul.github.io/biker_hero/](https://nurmohammadrahul.github.io/biker_hero/)

---

## 🚀 Features

- Responsive design for all screen sizes
- Modern UI with Tailwind CSS
- Hero section with call-to-action
- Featured bikes/products
- Testimonials or review section
- Footer with links and contact info

---

## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS**
- **JavaScript (Vanilla)**
